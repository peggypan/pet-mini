# 遛搭搭 · 运营后台

对应小程序 `chongwu/apps/wxapp` 的管理端，当前为 **纯前端界面 + Mock 数据**，后续对接 **微信云开发 / 云数据库** 与云函数。

## 功能模块（与小程序对齐）

| 模块 | 说明 |
|------|------|
| 工作台 | 待办汇总、核心指标 |
| 用户与宠物 | C 端用户、宠物档案、电子宠证快照 |
| 社区动态 | 帖子审核、评论、话题、分区 |
| 搭子广场 | 遛狗/社交邀约帖 |
| 活动 | 活动列表、报名核销、活动发布资质（无保证金） |
| 友好地图 | 用户标点审核、积分发放 |
| 寻宠救助 | 走失/招领/领养/救助信息 |
| 商家 | 入驻审核、门店与服务 |
| 主理人与俱乐部 | 成为主理人审核、活动发布资质、俱乐部管理、成员 |
| 内容运营 | 首页 Banner、开机广告 |
| 积分 | 积分流水与规则 |
| 系统设置 | 敏感词、社区分区 |

## 本地运行

```bash
cd chongwu-admin
npm install
npm run dev
```

默认 http://localhost:5173 ，任意账号密码可进入（占位登录）。

## 界面特性（当前版本）

- 侧栏可折叠、面包屑、页面标题随路由更新  
- 菜单待办角标（Mock 数量，接云后可替换）  
- 工作台：指标卡片、快捷入口、待办、最近动态  
- 审核类列表：状态分段筛选 + 搜索 + 表格分页  
- 评论管理：支持楼中楼回复字段展示  
- 路由懒加载，首屏体积更小  

## 后续接入云开发（规划）

1. 云数据库集合命名与 `src/types` 中实体字段对齐  
2. `src/services/*` 替换 Mock 为 `wx.cloud` / HTTP 网关  
3. 管理端登录：云函数 + 管理员 openid 白名单  

详见 `docs/cloud-integration.md`。

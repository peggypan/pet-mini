# 最小上线 · P0 走测（约 1 小时）

从 [`TEST-CASES.md`](./TEST-CASES.md) 摘出的 **必过路径**：登录、宠物、搭子、社区、**双号私信**、**活动报名**。  
不测地图/商家/俱乐部/运营后台等。

**需要**：2 个微信号（A=主测，B=第二台真机）、云已部署 `api`、`checkCollections` 无 missing。

## P0 主路径（约 50 分钟）

按顺序打勾；**[B]** 表示必须账号 B 操作。

| ✓ | ID | 谁 | 操作 | 通过标准 |
|---|-----|-----|------|----------|
| ☐ | SYS-01 | A | 冷启动 → 同意隐私 | 进首页 Tab，无白屏 |
| ☐ | USER-01 | A | 进 **我的**，触发登录 | 云库 `users` 有 A 的记录 |
| ☐ | PET-01 | A | **宠物档案** 新建一只宠物 | `pets` 有数据；各页不再强弹建档 |
| ☐ | BUD-01 | A | **搭子发布** 一条（图+文案） | 发布成功 |
| ☐ | BUD-02 | A | **搭子广场** 下拉刷新 | 能看到刚发的帖 |
| ☐ | BUD-09 | B | B 打开 A 的 **搭子详情** | 能看；不能删 |
| ☐ | FOL-03 | A | A 在 B 的搭子详情点 **关注** | 关注成功（云 `user_follows` 可选查） |
| ☐ | FOL-04 | B | B 关注 A（任意入口：搭子/主页） | 聊天页可显示 **互关**（测私信前建议做） |
| ☐ | CHAT-02 | A | 搭子详情 → **私信/聊天** | 进入聊天页，有 `threadId` |
| ☐ | CHAT-03 | A | 发一条 **文字** | 发送成功，气泡在右 |
| ☐ | CHAT-04 | B | B 打开 **消息** → 同会话 | 几秒内看到 A 的消息 |
| ☐ | CHAT-05 | B | B **回复**一条 | A 端几秒内收到 |
| ☐ | CHAT-01 | A | 返回 **消息列表** | 会话一条、预览/标题正常（同人勿重复多条） |
| ☐ | SOC-02 | A | **社区** 发一条动态 | 发布成功 |
| ☐ | SOC-01 | B | **社区** 下拉刷新 | 能看到 A 的动态或空态不报错 |
| ☐ | SOC-04 | B | 进 A 的 **动态详情** 留 **评论** | 评论可见 |
| ☐ | EVT-02 | A | **发布活动**（一场即可） | 发布成功 |
| ☐ | EVT-03 | A | 打开 **活动详情** | 信息正确 |
| ☐ | EVT-S1 | B | B 在该活动 **报名** | 出现核销码/二维码 |
| ☐ | EVT-S3 | B | B **我的活动** → 我参加的 | 列表含该活动 |
| ☐ | EVT-S4 | A | A **主办方报名列表** | 能看到 B 的报名 |
